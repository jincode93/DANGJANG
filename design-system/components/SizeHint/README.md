# SizeHint

상품 사진 위나 사이즈 영역에서 비교 기능으로 이끄는 안내로, 추천 알약과 로그인 카드 두 가지가 있다.

## 소비자가 제공할 것
- 추천 알약 `dj-hint`: 추천 사이즈("M 추천", `primary-text`)와 행동("기준 옷과 겹쳐보기"), `chevron-right`.
- 로그인 카드 `dj-login`: 안내 문장과 "로그인하기 ›" 링크. 비회원일 때만.

## 규칙
- 추천 알약은 대표 이미지 왼쪽 아래(왼쪽 `space-gutter`). 바탕 `bg-subtle`, 모서리 `radius-full`.
- 로그인 카드 오른쪽 장식은 CSS로 그린 초록 빛 번짐이다. 그림이나 글자를 올리지 않는다.
