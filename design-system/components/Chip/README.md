# Chip

세부 종류처럼 목록을 고르는 칩으로, 하나를 누르면 초록 면으로 켜진다.

## 소비자가 제공할 것
- `aria-pressed`로 상태를 넘긴다. 켜진 칩은 `primary` 면에 `on-primary` 글자.
- 라벨은 명사 하나("롱패딩", "점퍼/자켓").
- 추천할 칩에는 `<span class="dj-badge">비교 추천</span>`을 칩 안에 넣는다. 칩 위 가운데에 걸친다.

## 규칙
- 칩 묶음은 `dj-chips`. 넘치면 줄바꿈 대신 가로 스크롤 한 줄.
- 안쪽 여백 14 · 20px, 모서리 `radius-md`, 테두리 `line`, 글자 14px 500.
- 사이즈 선택에는 쓰지 않는다. 사이즈는 `SizeChip`.
