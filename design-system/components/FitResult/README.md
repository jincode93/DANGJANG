# FitResult

고른 사이즈를 내 기준 옷과 부위별로 비교한 결과로, 요약 카드와 부위 라벨 두 가지가 있다.

## 소비자가 제공할 것
- 요약 카드 `dj-summary`: 판정 문장("XL 사이즈는 내 기준 옷과 비슷해요"), 차이 설명 한 줄, 판정별 부위 개수("3곳").
- 부위 라벨 `dj-fit-pill`: 도식 위에 얹는 "부위 차이" 라벨("어깨 −1"). 차이는 기준 옷 대비 cm, 마이너스는 U+2212.

## 규칙
- 부위 판정 낱말은 세 가지만: 비슷해요 · 넉넉해요 · 부족해요. 사이즈 칩 판정(작아요·커요)과 섞지 않는다.
- 색 토큰: 글자 `fit-match`·`fit-loose`·`fit-tight`, 라벨 면 `dj-fit-pill--match`·`--loose`·`--tight`.
- 판정은 색만으로 알리지 않는다. 낱말이나 숫자를 꼭 함께 쓴다. `fit-match`(초록)와 `fit-tight`(빨강)는 색각 이상 사용자가 구분하기 어렵다.
- 판정 기준 숫자는 화면에 쓰지 않는다.
