# SizeTable

부위별 실측을 사이즈마다 보여 주는 표로, 기준 옷이 있으면 기준 옷·고른 사이즈·차이 세 줄로 바뀐다.

## 소비자가 제공할 것
- 머리 줄: 부위마다 번호(`<i>1</i>`)와 이름. 번호는 도식의 번호와 같게.
- 기준 옷이 없을 때: 사이즈마다 한 줄. 있을 때: "내 기준 옷", 고른 사이즈(`is-picked`), "차이"(`is-diff`).
- 아래 안내 한 줄(`<p>`): 단면 실측 기준과 오차.

## 규칙
- 칸 높이 40px(머리 52px), 너비 72px, 테두리 `line`. 넘치면 표만 가로 스크롤.
- 수치 `text-tertiary` 12px, tabular-nums. 차이 줄은 `primary-text` 600. 같으면 "같음".
