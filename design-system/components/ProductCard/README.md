# ProductCard

목록·추천에 쓰는 2열 상품 카드로, 가격 아래에 내 옷 기준 한 줄 판정을 붙인다.

## 소비자가 제공할 것
- 3:4 이미지, 브랜드(또는 중고 등급), 상품명(두 줄까지), 가격, 할인율.
- 판정 한 줄: 가장 중요한 판정 하나만("M이 내 옷과 비슷해요").
- 라벨: 중고 거래 상품은 `dj-label--sale` "판매 상품", 당장에서 산 옷은 `dj-label--verified` "당장 구매 인증".

## 규칙
- 판매 상품이 내 옷과 함께 보이면 항상 "판매 상품" 라벨을 붙인다.
- 할인율은 `danger` 색, 가격은 `tabular-nums`.
- 기준 옷이 없으면 판정 줄을 빼고, 대신 비우지 않는다.
