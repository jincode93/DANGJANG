# OptionSelect

구매 전에 컬러·사이즈를 고르고 수량을 정하는 옵션 묶음으로, 옵션 선택 시트 안에 쓴다.

## 소비자가 제공할 것
- 드롭다운 `dj-select`: 옵션 이름("컬러", "사이즈")과 `chevron-down`.
- 고른 옵션 `dj-option`: 이름("챠콜 / L"), 수량 `dj-stepper`(빼기 · 수 · 더하기), 가격, 빼기 버튼(`close`).
- 합계 `dj-total`: "총 N개"와 금액.

## 규칙
- 고른 옵션이 여러 개면 목록이 최대 400px까지 늘고 그 안에서 스크롤한다.
- 아이콘만 있는 버튼에는 `aria-label`. 수량은 `output`으로 읽어 준다.
- 아래 버튼은 `dj-btn-pair`("장바구니", "구매").
