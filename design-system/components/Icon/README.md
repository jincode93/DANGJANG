# Icon

당장 아이콘 세트로, 24px 그리드 위에 1.8px 둥근 선으로 그린 아이콘 203종이고 각각 Line과 Fill 두 벌이 있다.

## 소비자가 제공할 것
- 아이콘 이름(`home`, `heart-fill` …)과 크기(`dj-icon`, `dj-icon--md`, `dj-icon--sm`). 미리보기에서 이름·한국어로 찾고 Line/Fill을 바꿔 볼 수 있다.
- 아이콘만 있는 버튼은 `dj-icon-btn`에 넣고 `aria-label`로 행동을 쓴다("찜하기", "공유").
- 글자와 함께 쓰면 장식이므로 `aria-hidden="true"`.

## 규칙
- 인라인 SVG로 넣는다. 색은 `currentColor`라 부모 글자색을 따른다.
- `-fill`은 선택 상태에만 쓴다. 같은 화면에서 같은 아이콘의 선·채움을 동시에 쓰지 않는다.
- Fill의 파낸 부분은 SVG `mask`로 만든다. 한 페이지에 여러 개를 인라인으로 넣을 때는 `mask` id가 겹치지 않게 아이콘마다 바꾼다.
- SVG 파일(Assets › Icons)은 두 테마 모두에서 보이도록 잉크가 `black-60`(#777777)으로 고정돼 있다. Figma나 `<img>`로 쓸 때는 SVG의 `stroke`·`fill`을 쓰려는 글자색으로 바꾼다.
- 없는 아이콘이 필요하면 같은 그리드·선 두께로 새로 그려 세트에 추가한다.
