# 신기능 제안

새 기능 아이디어를 제안하는 곳이다. 정책 문서에는 확정된 규칙만 두므로, 아직 합의되지 않은 기능은 여기에 둔다. 합의되면 정책(`docs/policy/`)으로 옮긴다.

## 만드는 법

1. 제안마다 새 파일을 하나 만든다. 파일 이름은 `기능이름.md` (예: `코디-추천.md`).
2. 아래 양식을 복사해서 채운다.
3. PR로 올린다. 다른 사람의 제안 파일은 고치지 않는다. 의견은 PR 댓글로 남긴다.

## 양식

```markdown
# 기능 이름

- 제안한 사람:
- 날짜:

## 어떤 문제를 푸나요?
누가, 언제, 무엇 때문에 불편한지. 근거가 없으면 "가정"이라고 적는다.

## 어떻게 푸나요?
기능을 한두 문단으로.

## 지금 정책과의 관계
기대는 정책 ID(예: BASE-02, REC-06), 바뀌어야 할 정책, 새로 필요한 용어.

## 어떻게 검증하나요?
유저 테스트, 지표, 합격선.

## 아직 모르는 것
```
