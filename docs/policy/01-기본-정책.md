# 01. 기본 정책

DANGJANG의 모든 기능 정책이 딛고 서는 바닥 규칙이다. 옷을 어떻게 나누고(분류 체계), 치수를 어떻게 재고(측정 방식), 브랜드 치수를 어떻게 우리 기준으로 바꾸는지(보정)를 정한다.

- 이 문서에는 확정된 규칙만 둔다. 아직 정하지 않은 것은 `docs/open-questions.md`에 둔다.
- 용어의 뜻은 `docs/glossary.md`가 기준이다.
- 규칙마다 ID를 붙인다. 다른 문서는 장 번호가 아니라 ID로 가리킨다.

---

## 1. 분류 체계 (CAT)

### CAT-01 대분류
상의, 하의, 아우터 3가지다.

### CAT-02 세부 종류
팀이 합의한 15가지다. 사용자가 고르고 화면에 보인다.

| 대분류 | 세부 종류 |
|---|---|
| 상의 | 긴팔 셔츠, 긴팔 티셔츠, 반팔 셔츠, 반팔 티셔츠, 후드티 |
| 하의 | 긴바지, 반바지, 긴치마, 짧은 치마 |
| 아우터 | 가디건, 점퍼/자켓, 숏코트, 롱코트, 숏패딩, 롱패딩 |

### CAT-03 세부 종류는 꼭 고른다
옷장의 옷과 상품은 모두 세부 종류를 가진다. 세부 종류를 고르지 않은 옷은 담지 않는다. 기준 옷이 세부 종류마다 정해지기 때문이다(BASE-01).

### CAT-04 세부 종류가 같은지는 세부 종류로만 판단한다
치수 양식이 같아도(예: 긴팔 셔츠와 긴팔 티셔츠) 세부 종류가 다르면 다른 종류다.

### CAT-05 치수 양식
세부 종류마다 어떤 부위를 재는지 정한 내부 양식 8가지다. 사용자에게 보이지 않는다.

| 치수 양식 | 세부 종류 | 재는 부위 |
|---|---|---|
| 긴팔 상의 | 긴팔 셔츠, 긴팔 티셔츠, 후드티 | 총장, 어깨, 가슴, 소매, 암홀, 밑단, 소매부리 |
| 반팔 상의 | 반팔 셔츠, 반팔 티셔츠 | 총장, 어깨, 가슴, 전체소매, 암홀, 밑단, 소매부리 |
| 짧은 아우터 | 가디건, 점퍼/자켓, 숏코트, 숏패딩 | 총장, 어깨, 가슴, 소매, 암홀, 밑단, 소매부리 |
| 긴 아우터 | 롱코트, 롱패딩 | 총장, 어깨, 가슴, 소매, 암홀, 밑단, 소매부리 |
| 긴바지 | 긴바지 | 총장, 허리, 엉덩이, 허벅지, 밑위, 밑단 |
| 반바지 | 반바지 | 총장, 허리, 엉덩이, 허벅지, 밑위, 밑단 |
| 긴치마 | 긴치마 | 총장, 허리, 엉덩이, 밑단 |
| 짧은 치마 | 짧은 치마 | 총장, 허리, 엉덩이, 밑단 |

### CAT-06 품 부위와 길이 부위
옷을 펴 놓고 **가로로 재면 품, 세로로 재면 길이**다.

| 구분 | 부위 |
|---|---|
| 품 부위 | 가슴, 어깨, 암홀, 밑단, 소매부리, 허리, 엉덩이, 허벅지 |
| 길이 부위 | 총장, 소매, 전체소매, 밑위 |

### CAT-07 몸통 품 부위
품 부위 중 재는 위치가 옷 길이와 상관없는 부위다.

| 대분류 | 몸통 품 부위 |
|---|---|
| 상의, 아우터 | 가슴, 어깨, 암홀 |
| 하의 | 허리, 엉덩이, 허벅지 |

밑단과 소매부리는 들어가지 않는다. 옷 길이에 따라 재는 위치가 바뀐다(반팔 소매부리는 팔뚝, 긴팔은 손목).

### CAT-08 핵심 부위
치수 양식마다 꼭 있어야 하는 부위다. 이 부위가 어디에 쓰이는지는 기능 정책에서 정한다.

| 치수 양식 | 핵심 부위 |
|---|---|
| 긴팔 상의, 짧은 아우터, 긴 아우터 | 총장, 가슴, 어깨, 소매 |
| 반팔 상의 | 총장, 가슴, 어깨 |
| 긴바지, 반바지 | 허리, 엉덩이, 밑위, 총장 |
| 긴치마, 짧은 치마 | 허리, 엉덩이, 총장 |

어깨선 모양(드롭숄더, 래글런 등)과 상관없이 같은 치수 양식이면 핵심 부위가 같다. 어깨선 모양으로 세부 종류를 더 나누지 않는다.

## 2. 측정 방식 (MEA)

### MEA-01 하나의 기준
모든 치수는 DANGJANG 측정 방식 하나로 비교한다. 브랜드가 낸 값도, 사용자가 잰 값도 이 기준으로 맞춘다.

### MEA-02 공통 원칙
- 단위는 cm, 값은 단면이다. 둘레는 쓰지 않는다.
- 옷을 평평하게 펴고, 늘이지 않고, 지퍼와 단추를 잠근 상태에서 잰다.

### MEA-03 부위별 측정 방식

| 부위 | 재는 방법 |
|---|---|
| 상의 총장 | 옆목점에서 밑단 끝까지 수직 |
| 어깨 | 좌우 어깨 봉제선 끝 사이 직선 |
| 가슴 | 겨드랑이 바로 아래, 좌우 봉제선 끝 사이 직선 |
| 소매 | 어깨 봉제선 끝에서 소매 끝까지 |
| 전체소매 | 뒷목 중심에서 소매 끝까지 |
| 암홀 | 어깨 끝에서 겨드랑이까지 직선 |
| 상의 밑단 | 밑단 끝 좌우 직선 |
| 소매부리 | 소매 끝 좌우 직선 |
| 허리 | 허리 밴드 위 끝 좌우 직선. 고무줄은 늘이지 않는다 |
| 엉덩이 | 바지는 가랑이 봉제선 높이의 좌우 직선. 치마는 허리 위 끝에서 18cm 아래의 좌우 직선 |
| 허벅지 | 가랑이 봉제선 바로 아래 좌우 직선 |
| 밑위 | 허리 밴드 위 끝에서 앞쪽 가랑이 봉제선까지 |
| 바지 총장 | 허리 밴드 위 끝에서 바깥 옆선을 따라 밑단까지 |
| 치마 총장 | 허리 밴드 위 끝에서 옆선을 따라 밑단까지 |
| 하의 밑단 | 밑단 끝 좌우 직선 |

### MEA-04 범위를 벗어난 값
부위별 정상 범위를 벗어난 값은 하나의 처리로 다룬다. 둘레를 넣은 것처럼 보이는 값 등 원인별로 예외를 따로 두지 않는다. 정상 범위 값은 검토 중이다(`docs/open-questions.md`).

## 3. 보정 (CAL)

### CAL-01 브랜드는 자기 방식대로 재고, 우리가 맞춘다
브랜드에게 우리 방식으로 다시 재라고 하지 않는다. 브랜드는 입점할 때 자기 측정 방식을 제출하고, DANGJANG이 우리 측정 방식(MEA-03)으로 바꿔서 비교한다. 브랜드가 낸 원래 값도 함께 보관한다.

### CAL-02 입점 때 받는 것
- 그 세부 종류의 핵심 부위(CAT-08)를 모든 사이즈에 넣는다. 하나라도 비면 등록할 수 없다.
- 측정 방식은 세부 종류 단위로 받는다. 받는 항목은 우리 방식과 달라질 수 있는 곳이다.

| 항목 | 우리 방식 |
|---|---|
| 단면 / 둘레 | 단면 |
| 상의 총장 시작점 | 옆목점 |
| 소매 시작점 | 어깨 봉제선 끝 |
| 엉덩이 높이 | 가랑이 봉제선 높이 (치마는 허리 위 끝에서 18cm 아래) |
| 허벅지 높이 | 가랑이 봉제선 바로 아래 |
| 하의 길이 시작점 | 허리 밴드 위 끝 |

### CAL-03 계산으로 바꾸는 보정
| 브랜드 방식 | 바꾸는 법 |
|---|---|
| 둘레 | ÷ 2 |
| 소매를 뒷목 중심부터 잼(화장) | 화장 − 어깨 ÷ 2 |

### CAL-04 견본으로 구하는 보정
계산으로 바꿀 수 없는 차이(상의 총장 시작점, 엉덩이·허벅지 높이, 하의 길이 시작점)는 견본으로 구한다. 브랜드가 입점할 때 세부 종류마다 견본 한 벌을 브랜드 방식과 우리 방식으로 둘 다 재서 내고, 그 차이를 그 브랜드·세부 종류의 보정값으로 쓴다.

### CAL-05 보정의 한계
보정으로 바꿀 수 있는 것은 측정 방식의 차이뿐이다. 같은 방식으로 재도 사람마다 생기는 오차는 남는다.
