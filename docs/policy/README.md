# 정책

DANGJANG이 어떻게 동작해야 하는지 정한 규칙이다. 확정된 규칙만 둔다.

## 원칙

규칙이 없는 상황을 만나면 원칙으로 판단한다.

1. **정확하지 않으면 정확하지 않다고 말한다.** 부족한 데이터와 애매한 추천은 화면에 그대로 드러낸다. 틀린 확신보다 "모른다"가 신뢰를 덜 잃는다.
2. **조용한 실패는 없다.** 잘못된 입력, 품절, 비교할 수 없음은 사용자에게 보이고, 다음에 할 일을 알려 준다.
3. **사용자가 넣은 정보만 쓴다.** 사용자가 직접 넣지 않은 신체·옷 정보는 가져오지 않는다.
4. **수고보다 쓸모를 먼저 보여 준다.** 사용자는 쓸모가 보일 때만 정보를 넣는다(인터뷰 5/5).
5. **한 뜻은 한 말로.** 같은 판정을 화면마다 다른 단어로 말하지 않는다.
6. **정확도를 낮춰서 부담을 줄이지 않는다.** 정확한 추천이 서비스의 정체성이다. 부담은 필수 항목을 줄여서가 아니라 데이터를 가져오는 방법(구매 확정, 상품 링크, 입점 데이터)으로 줄인다. 상품 데이터의 정확성은 입점과 어드민에서 지킨다(CAL, PRD-02).
