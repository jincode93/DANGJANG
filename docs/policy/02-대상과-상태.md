# 02. 대상과 상태

DANGJANG이 다루는 대상(상품, 옷장의 옷, 기준 옷, 비교 옷)과 사용자 상태를 정한다. 기본 정책(`01-기본-정책.md`) 위에 선다.

- 확정된 규칙만 둔다. 아직 정하지 않은 것은 `docs/open-questions.md`에 둔다.
- 용어의 뜻은 `docs/glossary.md`가 기준이다.

---

## 1. 상품 (PRD)

### PRD-01 상품은 입점 절차로만 들어온다
출시 전이라 기존 상품은 없다. 상품은 대분류와 세부 종류를 가지고, 사이즈마다 핵심 부위 치수가 있다(CAL-02).

### PRD-02 상품 상태
상품은 검사를 통과해야 노출된다. 자동 검사가 먼저 보고, 걸린 상품만 담당자가 본다.

```
검사 대기 ─ 통과 ─→ 노출
    └─ 걸림 ─→ 보류 ─ 판매자 수정 ─→ 검사 대기
```

보류하면 담당자가 판매자에게 어느 사이즈의 어느 칸이 왜 걸렸는지 알리고 수정을 요청한다.

### PRD-03 사이즈 상태
사이즈마다 판매 중 또는 품절이다.

## 2. 옷장의 옷 (CLO)

### CLO-01 잘 맞는 옷만 담는다
등록할 때 핏을 묻지 않는다. 안 맞는 옷을 관리하는 기능은 두지 않는다.

### CLO-02 옷이 가지는 정보
대분류, 세부 종류, 사이즈, 치수(DANGJANG 측정 방식, MEA-03). 세부 종류는 꼭 있어야 한다(CAT-03).

### CLO-03 치수 상태
| 상태 | 뜻 | 할 수 있는 것 |
|---|---|---|
| 치수 완료 | 그 치수 양식의 핵심 부위(CAT-08)가 모두 있다 | 기준 옷이 될 수 있다 |
| 치수 부족 | 핵심 부위가 하나라도 없다 | 옷장에는 있지만 기준 옷이 될 수 없다. 치수를 채우도록 안내한다 |

### CLO-04 반품한 옷은 담지 않는다
반품은 안 맞는 옷으로 본다.

### CLO-05 같은 옷을 다시 등록하면 막지 않고 알린다
같은 상품의 같은 사이즈를 같은 옷으로 본다. 같은 옷을 두 벌 사는 경우가 있어 막지 않는다.

### CLO-06 세부 종류를 바꿔도 같은 부위 값은 유지한다

### CLO-07 옷 삭제는 실행 취소할 수 있다

## 3. 기준 옷 (BASE)

### BASE-01 세부 종류마다 하나
기준 옷은 세부 종류마다 하나다. 그 세부 종류 상품을 볼 때 쓴다. 대분류 기준 옷은 두지 않는다.

세부 종류가 다른 옷은 기준 옷으로 쓰지 않는다. 기준 옷이 없으면 같은 대분류의 옷으로 자동 비교한다(CMP-04). 사용자가 비교 옷을 직접 고를 수도 있다(CMP-01). 대분류끼리는 비교하지 않는다.

### BASE-02 상품을 볼 때 쓰는 기준 옷
```
상품과 세부 종류가 같은 기준 옷이 있나?
 ├─ 있음 → 그 기준 옷
 └─ 없음 → 자동 비교할 옷이 있나? (CMP-04)
            ├─ 있음 → 자동 비교
            └─ 없음 → 기준 옷 없음
```

### BASE-03 처음 담은 옷이 자동으로 기준 옷이 된다
세부 종류에 처음 담긴 치수 완료 옷이 그 세부 종류의 기준 옷이 된다. 치수 부족 옷은 기준 옷이 될 수 없다.

### BASE-04 기준 옷을 바꾸는 곳은 두 곳뿐이다
- 내 옷장 목록: 세부 종류별로 기준 옷을 고른다. 옷이 있는 세부 종류만 보여 준다.
- 등록할 때 "기준 옷으로" 체크

옷 상세에서는 기준 옷을 바꿀 수 없다. 바꿀 때는 확인창에 지금 기준 옷과 새 기준 옷의 치수 차이를 보여 주고, 바꾼 뒤에는 실행 취소할 수 있다.

### BASE-05 기준 옷의 치수를 고칠 때 확인을 받는다
그 기준 옷을 쓰는 모든 상품의 추천이 바뀌기 때문이다. 확인창에 치수 차이를 보여 준다.

### BASE-06 기준 옷을 지우면 같은 종류에서 먼저 담은 옷이 이어받는다
같은 세부 종류에서 가장 먼저 담은 치수 완료 옷이 이어받는다. 이어받을 옷이 없으면 비워 둔다. 삭제 알림에 누가 이어받았는지 알린다. 이어받을 옷이 없으면, 이제 그 세부 종류 상품은 자동 비교(CMP-04)나 기준 옷 없음이 된다는 것을 알린다.

### BASE-07 기준 옷의 세부 종류를 바꾸면 삭제와 등록으로 본다
옛 세부 종류에서는 지운 것처럼 이어받고(BASE-06), 새 세부 종류에서는 새로 담은 것처럼 그 종류에 기준 옷이 없을 때만 기준 옷이 된다(BASE-03). 바꾸기 전에 확인을 받는다.

## 4. 비교 옷 (CMP)

### CMP-01 비교 옷은 상품 하나와만 견준다
상품 상세에서 "교체하기"로 고른 옷, 또는 기준 옷이 없을 때 자동으로 고른 옷(CMP-04)이다. 지금 보고 있는 상품 하나와만 비교하고, 기준 옷을 바꾸지 않는다. 다른 상품의 추천은 그대로다.

### CMP-02 같은 대분류의 옷만 고를 수 있다
고를 수 있는 목록에는 상품과 같은 대분류의 옷만 보여 준다. 서로 비교하지 않는 조합(REC-02, 치마와 바지)은 뺀다.

### CMP-03 치수 완료 옷만 비교 옷이 될 수 있다
기준 옷과 같은 자격이다. 치수 부족 옷은 고를 수 없고, 치수를 채우도록 안내한다.

### CMP-04 기준 옷이 없으면 비교 옷을 자동으로 고른다
상품과 세부 종류가 같은 기준 옷이 없고, 같은 대분류에 고를 수 있는 옷(CMP-02, CMP-03)이 있으면 아래 순서로 하나를 골라 비교한다.

| 순위 | 고르는 기준 |
|---|---|
| 1 | 상품과 치수 양식(CAT-05)이 같은 옷 |
| 2 | 같은 대분류의 나머지 옷 |
| 같은 순위 안 | 자기 세부 종류의 기준 옷인 옷이 먼저, 그다음 먼저 담은 옷 |

- 비교 결과를 보고 옷을 고르지 않는다. 순서는 정해져 있고, 같은 옷장이면 같은 상품에 늘 같은 옷이 골라진다.
- 비교하는 부위와 보여 주는 것은 REC-02, REC-07, REC-08을 따른다.
- 사용자가 "교체하기"로 다른 옷을 고르면 그 옷으로 비교한다(CMP-01).

## 5. 사용자 상태 (USR)

사용자 상태는 세 가지 축으로 나눈다. 기준 옷이 세부 종류마다 있어서 상품마다 비교 상태가 달라서다.

### USR-01 계정 상태
비회원 / 회원

### USR-02 옷장 상태 (회원만)
옷 없음 / 옷 있음

### USR-03 비교 상태 (상품마다)
BASE-02로 정해진다.

| 비교 상태 | 뜻 |
|---|---|
| 기준 옷 있음 | 상품과 세부 종류가 같은 기준 옷으로 비교한다 |
| 자동 비교 | 기준 옷이 없어 같은 대분류의 옷으로 비교한다(CMP-04) |
| 기준 옷 없음 | 기준 옷도, 자동 비교할 옷도 없다 |

비회원과 옷이 없는 회원은 언제나 "기준 옷 없음"이다.
