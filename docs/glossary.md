# 용어집

DANGJANG 문서에서 쓰는 용어의 뜻은 이 문서 한 곳에서만 정한다. 다른 문서는 뜻을 다시 쓰지 않고 이 문서를 가리킨다. 확정된 용어만 둔다.

## 서비스

| 용어 | 뜻 |
|---|---|
| DANGJANG | "당신의 옷장"의 줄임말. 0에서 1로 새로 만드는 패션 커머스 서비스. 다른 패션 커머스와의 차별점은 옷장이다 |

## 분류

| 용어 | 뜻 | 규칙 |
|---|---|---|
| 대분류 | 상의, 하의, 아우터 | CAT-01 |
| 세부 종류 | 팀이 합의한 옷 종류 15가지. 사용자가 꼭 고르고 화면에 보인다. "같은 종류"를 판단하고 기준 옷을 정하는 단위 | CAT-02, CAT-03, CAT-04 |
| 치수 양식 | 세부 종류마다 어떤 부위를 재는지 정한 내부 양식 8가지. 사용자에게 보이지 않는다 | CAT-05 |
| 부위 | 치수를 재는 자리. 총장, 어깨, 가슴, 소매, 전체소매, 암홀, 밑단, 소매부리, 허리, 엉덩이, 허벅지, 밑위 | CAT-05 |
| 품 부위 | 옷을 펴 놓고 가로로 재는 부위 | CAT-06 |
| 길이 부위 | 옷을 펴 놓고 세로로 재는 부위 | CAT-06 |
| 몸통 품 부위 | 품 부위 중 재는 위치가 옷 길이와 상관없는 부위. 상의·아우터는 가슴·어깨·암홀, 하의는 허리·엉덩이·허벅지 | CAT-07 |
| 핵심 부위 | 치수 양식마다 꼭 있어야 하는 부위 | CAT-08 |

## 측정

| 용어 | 뜻 | 규칙 |
|---|---|---|
| 실측 | 옷을 평평하게 펴 놓고 잰 치수 | MEA-02 |
| 단면 | 옷을 펴 놓았을 때 한쪽 끝에서 다른 쪽 끝까지의 직선 길이. DANGJANG의 치수 단위 | MEA-02 |
| 둘레 | 옷을 한 바퀴 돈 길이. 단면의 약 2배. DANGJANG은 쓰지 않고 단면으로 바꾼다 | CAL-03 |
| DANGJANG 측정 방식 | 부위마다 어디서 어디까지 재는지 정한 우리 기준. 모든 치수를 이 기준으로 비교한다 | MEA-01, MEA-03 |
| 브랜드 측정 방식 | 브랜드가 입점할 때 제출하는, 그 브랜드가 실제로 재는 방법 | CAL-02 |
| 보정 | 브랜드 측정 방식으로 잰 값을 DANGJANG 측정 방식의 값으로 바꾸는 일 | CAL-01 |
| 보정값 | 견본 한 벌을 두 방식으로 재서 구한 차이. 브랜드·세부 종류마다 있다 | CAL-04 |
| 정상 범위 | 부위별로 받아들이는 값의 범위. 벗어나면 하나의 처리로 다룬다 | MEA-04 |
| 옆목점 | 어깨선과 목둘레가 만나는 점. 상의 총장의 시작점 | MEA-03 |
| 뒷목 중심 | 뒷목 가운데 봉제선. 전체소매의 시작점 | MEA-03 |
| 화장 | 뒷목 중심에서 소매 끝까지 잰 소매 길이. 일부 브랜드의 소매 표기 | CAL-03 |
| 가랑이 봉제선 | 바지 앞뒤와 좌우 봉제선이 만나는 십자 지점. 엉덩이·허벅지·밑위를 재는 기준점 | MEA-03 |

## 대상과 상태

| 용어 | 뜻 | 규칙 |
|---|---|---|
| 상품 | 입점 절차로 들어와 DANGJANG에서 파는 옷. 검사 대기 / 노출 / 보류 상태를 가진다 | PRD-01, PRD-02 |
| 옷장 | 사용자가 잘 맞는 옷을 담아 두는 곳 | CLO-01 |
| 옷장의 옷 | 옷장에 담긴 옷 한 벌. 대분류, 세부 종류, 사이즈, 치수를 가진다 | CLO-02 |
| 치수 완료 / 치수 부족 | 옷장의 옷에 핵심 부위가 모두 있는지 여부. 치수 부족 옷은 기준 옷이 될 수 없다 | CLO-03 |
| 기준 옷 | 상품과 비교하는 기준이 되는 옷장의 옷. 세부 종류마다 하나이고, 그 세부 종류 상품을 볼 때 쓴다. 대분류 기준 옷은 없다 | BASE-01 |
| 비교 옷 | 그 상품 하나와만 견주는 옷. 상품 상세에서 "교체하기"로 고르거나, 기준 옷이 없을 때 자동으로 골라진다. 기준 옷을 바꾸지 않는다 | CMP-01, CMP-04 |
| 자동 비교 | 상품과 세부 종류가 같은 기준 옷이 없을 때, 정해진 순서로 같은 대분류의 옷을 골라 몸통 품 부위만 비교하는 것. 추천 사이즈만 보여 준다 | CMP-04 |
| 계정 상태 | 비회원 / 회원 | USR-01 |
| 옷장 상태 | 옷 없음 / 옷 있음 | USR-02 |
| 비교 상태 | 상품마다 정해지는 상태. 기준 옷 있음 / 자동 비교 / 기준 옷 없음 | USR-03 |

## 기능

| 용어 | 뜻 | 규칙 |
|---|---|---|
| 추정값 | 빈 부위를 다른 부위 비율로 채운 값. DANGJANG은 만들지 않는다 | REG-08 |
| 종합 판정 | 사이즈 하나를 기준 옷과 견준 한마디. 비슷해요 / 커요 / 작아요 | REC-05 |
| 추천 상태 | 추천 결과의 종류. 추천 / 두 사이즈 사이 / 맞는 사이즈 없음 / 가장 맞는 사이즈 품절 / 모든 사이즈 품절 | REC-06 |
| 정답표 | 상품 치수와 기준 옷의 쌍에 기대 결과를 적은 표. 추천 규칙이 맞는지 잰다 | REC-11 |
| 주문 상태 | 배송 중 / 배송 완료 / 구매 확정 / 옷장 담김 / 반품 신청 | ORD-01 |
| 구매 확정 | 배송 완료 뒤 사용자가 확정하거나 7일 뒤 자동으로 확정된 상태. 옷장 담기를 묻는 시점 | ORD-02, ORD-03 |
