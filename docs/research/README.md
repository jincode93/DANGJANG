## 숫자를 읽을 때 주의

- **설문 인원:** 팀 공식 기준은 유효 24명이다. 일부 분석은 구글 폼 원자료를 내보낸 시점에 따라 22명이나 23명을 썼다. 이 레포는 24명 기준 수치를 쓰고, 다른 기준을 쓸 때는 따로 적는다.
- **표본이 작다.** 설문 24명, 인터뷰 5명이다. 비율보다 "몇 명 중 몇 명"으로 읽고, 교차 분석은 방향 신호로만 본다.
- **인터뷰 참여자:** 공개 레포라 실명 대신 인터뷰이 A~E로 적었다.

| 표기 | 유형 | 특징 |
|---|---|---|
| 인터뷰이 A | 적극 확인형 | 여성, 키 170. 키로 거르고 몸무게로 다시 거름 |
| 인터뷰이 B | 적극 확인형 | 사이즈·키·몸무게 필터 → 사진 → 글 순서로 봄 |
| 인터뷰이 C | 적극 확인형 | 남성 24세. 쇼핑앱의 맞춤 체형 설정을 씀 |
| 인터뷰이 D | 느낌 판단형 | 착샷의 느낌을 봄. 체형 정보는 거의 안 봄 |
| 인터뷰이 E | 오프라인형 (비교군) | 남성 24세. 매장에서 입어 보고 삼 |
