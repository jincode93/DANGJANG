# 멘토링 1회차 (2026-09-23)

원본: 팀 공용 노션의 멘토링 회의록. 이 레포의 작업과 관련된 내용만 정리했다.

## 그때 팀의 상태

- 국내 이커머스 페인포인트 후보 6개 도출 → Gen Z로 타깃 압축 → 패션·뷰티 비교 후 패션 선택
- 경쟁사 분석 (TikTok Shop, Pinterest, 무신사, 29CM, 에이블리, 지그재그)
- 문제정의 v2와 가설 H1~H5 수립
- 합성 페르소나 60명으로 설문 문항 사전 점검
- 문제정의 v2: Gen Z는 마음에 드는 아이템을 발견한 뒤에도 "이게 나에게도 맞을까?"를 검증할 동료의 맥락이 없어, 구매 직전에 이탈하거나 사고 나서 후회한다.

## 멘토 피드백

**리서치와 문제정의**
- 시장조사, 경쟁사 분석, 출처 정리, 타깃 압축 과정이 꼼꼼하다.
- "뷰티는 개인차가 크고 패션은 유형화하기 쉽다"만으로는 카테고리 선택 근거가 부족하다. 어느 쪽에서 구매 포기·반품·후회가 더 큰지까지 비교하라.
- 결과 문서에는 작업 이력보다 현재의 결론과 근거를 먼저 둔다. 과정은 의사결정 기록으로 따로 남긴다.

**합성 페르소나**
- 합성 데이터는 검증 결과가 아니라 설문 문항 점검 도구다. 실제 사용자 데이터로 다시 검증하라.
- 솔루션을 암시하는 의향 질문을 줄이고, '나 같은 사람'의 기준은 1차로 중요성을 묻고 2차로 세부 기준(체형·스타일)을 물어라.

**AI 네이티브 문서화**
- GitHub에 PRD, 도메인 지식, 정책, 레퍼런스, 의사결정 기록을 폴더 단위로 관리하라.
- PRD는 P0 핵심 기능 중심으로, 처음 보는 디자이너·개발자도 이해할 수 있게 쓴다.

**솔루션과 프로토타입**
- 글로벌 이커머스 사례를 탐색하고, 여러 UX 시나리오를 만든 뒤 평가 기준으로 상위 3개 안을 고른다.
- 텍스트 PRD만이 아니라 실제로 작동하는 코드 프로토타입을 만든다.

**지표 제안**
- 고객 지표: 구매 포기율, 외부 재검색률, 구매 확신도, 결정 시간
- 사업 지표: 상품 상세 → 장바구니, 상품 상세 → 구매, 장바구니 → 구매 전환율
- 품질 지표: 반품률, 후기 유용성 평가
- 가드레일: 개인정보 제공 거부율, 후기 작성 이탈률, 특정 체형 편향

## 이 레포에서 반영한 것

- 결과와 과정을 나눔: `docs/research/`는 결론 중심, `logs/decision-log.md`는 과정 기록
- 문서와 프로토타입을 한 레포에서 관리
