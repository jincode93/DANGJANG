# 멘토링 3회차 (10월 중순, 정확한 날짜는 원본에 없음)

원본: 팀 공용 노션의 멘토링 3회차 피드백 정리.

## 멘토 피드백

**치수 입력 방법**
- 외부 링크나 구매내역에서 치수를 가져올 때, 꼭 계약한 브랜드가 아니어도 수치를 가져오는 것은 큰 문제가 되지 않을 것 같다. 수치를 가져와서 어떻게 보여줄지를 더 고민하라.
- 사진으로 인식할 때는 치수를 정말 정확하게 받아야 한다. 옷은 3cm만 달라도 완전히 다른 옷이 된다. 직접 개발해서 정확도를 올리기보다 기술적인 고려만 해 보거나, AI로 치수를 뽑은 뒤 사람이 보완하는 방법도 생각해 볼 만하다. 이때는 인건비를 고려해야 한다.
- 사용자가 직접 입력하는 것도 필요하다. 범위를 정해 두고, 잘못 입력했을 때 어떻게 알려 줄지 고민하라.

**옷장 활용**
- 지금은 핏 문제만 다루는데, 하나 정도 더 있으면 좋겠다.
- 이 문제를 푼 뒤 어떻게 확장할지 자세한 로드맵이라도 있으면 좋겠다.
- 옷장 카테고리가 지금은 상의·하의·아우터뿐인데 실제로는 훨씬 많다. 확장성을 꼭 고려하라. 아마존 같은 글로벌 이커머스를 참고하라. 옷이 많아졌을 때 사용자가 쉽게 찾는 방법도 고려하라.

**유저 테스트**
- 비교군을 잘 설계하라. 최대한 비슷한 두 그룹을 만들고, 이 기능이 있을 때와 없을 때 같은 시나리오를 따라가며 차이를 보라.

## 이 레포에서 반영한 것

- 옷장 그룹 8개 구조와 출시 수준 점검 목록의 치수 입력 검증 항목(A1)
- 로드맵은 10/30 작업에서 정리할 예정
