# 멘토링 3회차 (2026-10-16)

원본: Gemini 회의록과 스크립트, 팀 공용 노션의 3회차 피드백 정리. 중간발표 날이라 중간발표 자료로 진행 상황을 공유하고 피드백을 받았다.

## 팀이 공유한 것

- 타깃·도메인 선정, 문제정의, 합성 페르소나로 설문 점검, 설문 24명 결과 (멘토는 이미 본 내용이라 빠르게 넘어감)
- 솔루션 선정: 문제 해결력 × 기간 내 실행 가능성으로 아이디어를 나누고, 공통으로 나온 "기존 데이터를 활용한 핏 예측"으로 방향을 잡음
- Figma 와이어프레임: 기준 옷과 사려는 옷의 사이즈 차이를 점선·실선 도식으로 비교하는 화면
- 옷 등록 방법 3가지: 상품 링크, 다른 쇼핑몰 구매내역 캡처, A4 용지를 기준 물체로 둔 사진 촬영 + 비전 인식

## 정한 것

- **의견 일치:** 기존 데이터를 활용한 핏 예측 기능을 솔루션 방향으로 둔다.
- **추가 논의 필요:** 사용자가 올린 사진을 AI로 먼저 재고, 사람이 나중에 보완·검증하는 방식.

## 멘토 피드백

**유저 테스트**
- 실제 출시가 아니라서 사용자 여정 전체를 똑같이 테스트하기는 어렵다. 매력적인 기능 하나를 집중해서 확인하고 싶다면 A/B 테스트가 필요하다.
- 기능이 있는 프로토타입과 없는 프로토타입을 비교하고, 실험군과 대조군은 나이·성별 분포가 같도록 층화해서 무작위로 나눠라.

**표준화의 한계**
- 브랜드마다 라벨 구조가 다르고, 실제 카테고리는 6~7단계까지 깊다. 신축성에 따라 같은 사이즈도 핏이 다르다. 사이즈만으로 완벽하게 표준화하기는 어렵다.
- 와이어프레임의 도식 비교 자체는 직관적이다. 비교할 옷을 사용자가 고를 수 있는 점도 좋다.

**사진 측정**
- 차이가 1~2cm면 괜찮지만 3~4cm를 넘으면 사용자가 믿지 않는다. 같은 상품을 다르게 찍어 값이 달라지면 오류와 어뷰징이 생긴다.
- PM으로 뽑히는 것이지 AI 엔지니어로 뽑히는 게 아니다. 구현 리소스를 추정해 두고 **우선순위에서 빼는 게 맞다.**
- 실물 사진은 찍되, 사이즈를 정확히 입력할 수 있는 칸은 따로 있어야 한다. 사용자가 늘면 같은 상품이 중복 등록되니, 같은 제품을 검증하는 방법도 PM 관점에서 고민하라.
- 등록이 "내 쇼핑몰 제품만"과 "AI 사진 측정" 두 가지로 끝나는 건 아쉽다. 불편하더라도 기본적인 입력 방법은 다 만들어 두라.

**수작업 검증 (팀 질문에 대한 답)**
- 처음부터 100% 자동화하지 않아도 된다. 초기 배달 앱처럼 수작업으로 시작해 나중에 자동화한 사례가 많다.
- AI가 먼저 대략적인 숫자를 주고, 담당자가 나중에 정확한 정보로 바꾸는 방식을 제안했다. 크롤링 흔적이 남지 않아 법적 위험이 없다.
- "일주일 안에 정확한 정보로 업데이트해 드려요" 같은 정책은 마케팅 포인트도 된다. 단, 인건비를 꼭 계산하라.
- 입력값이 기존 데이터와 너무 다르면 "잘못 입력하신 것 같다"고 알려 주는 장치도 둘 수 있다.

**정보의 정확성과 개인화**
- 정보는 정확해야 한다. 정확하지 않은 값에는 그 사실을 꼭 표시하라. 이 상품을 등록한 사람들의 평균 수치를 보여 주는 것도 방법이다.
- 사이즈만 보면 모델이 입으면 괜찮은데 내가 입으면 별로인 문제를 풀지 못한다. 키·몸무게 외에 사람 정보를 어디까지 받을지 고민하라.
- 사람마다 신경 쓰는 부위가 다르다. 콤플렉스가 있거나 강조해서 보고 싶은 부위를 먼저 보여 주는 맞춤 우선순위를 검토하라.
- 사용자가 직접 입력하지 않은 정보(예: 다른 서비스의 체성분 수치)는 개인정보라 마음대로 가져올 수 없다.

**확장성과 로드맵**
- 옷장이 핏만을 위한 것이면 회사 입장에서는 아쉽다. 옷장의 장기 목표는 모든 것을 고려해 잘 맞는 옷을 찾아 주는 코디이고, 그 여정의 첫 단계가 핏이어야 한다.
- 핏 다음에 붙이면 시너지가 큰 두 번째 기능을 리스트업하라. 뾰족하지만 매력적이지 않은 서비스로 끝날 수 있다.
- 옷이 많아지면 빨리 찾을 수 있게 옷장을 분류하는 방법을 미리 고민하라.
- 국내 UI보다 아마존 같은 글로벌 이커머스가 새 서비스를 넣을 수 있게 UI를 일관되게 만든 이유를 보라. 확장성을 고려했는지는 면접에서도 묻는다.
