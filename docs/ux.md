# UX·디자인 기준

정책이 정한 것을 화면에서 어떻게 보여 줄지 정한다. 무엇을 알려야 하는지는 정책(`docs/policy/README.md`)이 정하고, 이 문서는 어떻게 보이는지만 정한다. 확정된 것만 두고, 정하지 않은 것은 `docs/open-questions.md`에 둔다.

## 1. 디자인 기준

- 디자인 기준은 상품 상세 시안이다. 모든 화면을 상품 상세 시안의 토큰으로 통일한다. 파란 `--fit`과 검정 주 버튼은 없앤다.
- 주 버튼은 초록이다. 초록은 "주 행동"만 뜻한다. "내 옷"이나 "비슷해요"를 초록으로 표시하지 않는다.
- 글자와 버튼에 쓰는 진한 초록을 하나 더 둔다. 지금 초록 위 흰 글자는 대비가 2.52:1로 기준(4.5:1)에 못 미친다. 넓은 면과 도식은 지금 초록을 유지한다.

## 2. 비교 도식

- 어느 옷인지는 선 모양으로만 구분한다. 내 옷은 회색 점선, 상품은 검정 실선.
- 얼마나 다른지는 뱃지 색으로만 보여 준다. 가장 큰 차이의 뱃지를 크게 그린다.
- 치수가 없는 부위는 "정보 없음"으로 그린다. 상대 옷 값으로 채워 그리지 않는다.
- 다른 세부 종류끼리 비교할 때는 상품 도식만 그린다(REC-07).

## 3. 빈 상태

- 옷장에 옷이 없을 때 등록 전 비교 예시는 보여 주지 않는다. 문구와 첫 등록 쿠폰으로 안내한다.
