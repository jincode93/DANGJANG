# BottomSheet

화면 아래에서 올라오는 시트로, 옵션 선택처럼 지금 화면을 벗어나지 않는 짧은 작업에 쓴다.

## 소비자가 제공할 것
- 제목(`title-2`), 내용, 하단 행동 하나.
- `role="dialog"`와 `aria-label`. 열릴 때 포커스를 시트 안으로 옮긴다.

## 규칙
- 최대 높이 `sheet-max`(600px). 넘치면 시트 안에서 스크롤.
- 뒤 배경 `dim`(80%). 배경을 누르거나 80px 이상 끌어내리면 닫힌다.
- 위 모서리 `radius-lg`, 그림자 `shadow-sheet`.
