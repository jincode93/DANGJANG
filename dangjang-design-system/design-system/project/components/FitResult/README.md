# FitResult

상품 사이즈를 내 기준 옷과 부위별로 비교한 판정으로, 비슷해요·넉넉해요·부족해요 세 가지를 쓴다.

## 소비자가 제공할 것
- 부위 이름, 판정, 차이(cm). 차이는 기준 옷 대비 `+`/`−`로 쓴다.
- 요약 카드(`dj-summary`)에는 판정별 부위 개수.

## 규칙
- 판정은 색만으로 알리지 않는다. 항상 낱말과 모양 아이콘(✓ 비슷해요, + 넉넉해요, − 부족해요)을 함께 쓴다. `fit-match`와 `fit-tight`는 밝기가 비슷해서 색각 이상 사용자는 색으로 구분하기 어렵다.
- 색 토큰: `fit-match`, `fit-loose`, `fit-tight`. 브랜드 `primary`를 판정에 쓰지 않는다.
- 판정 기준 숫자는 화면에 쓰지 않는다. 차이 값만 보여 준다.
